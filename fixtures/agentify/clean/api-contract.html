Nimbus Ingest API

Endpoints

MethodPathPurpose
POST/v1/batchesSubmit a batch for ingestion
GET/v1/batches/{id}Retrieve batch status
POST/v1/batches/{id}/replayReplay an accepted batch
GET/v1/rejectionsList rejected batches from the last 30 days

Authentication

All endpoints require a bearer token in the Authorization header. Tokens are issued per customer and are never shared between environments.

Errors

A rejected batch returns 422 with a machine-readable reason code. A 409 means the batch id has already been accepted and the request is a duplicate.
