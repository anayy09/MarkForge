# Table Structures

A simple table:

| Name  | Value |
| ----- | ----- |
| Alpha | 1     |
| Beta  | 2     |

With alignment:

| Left | Centre | Right |
| :--- | :----: | ----: |
| a    |    b   |     c |

Cells containing inline formatting:

| Construct | Example                     |
| --------- | --------------------------- |
| Strong    | **bold**                    |
| Code      | `literal`                   |
| Link      | [text](https://example.com) |
